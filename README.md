# AI UX Trends & Innovations Website

A comprehensive research website showcasing AI UI/UX trends, innovations, and design patterns from 2024-2026.

## Features

- **Trends Report**: Interactive report covering 2024-2025 retrospective, 2026 trends, core paradigm shifts, and practical applications
- **Innovation Catalog**: Searchable table of 26 innovative AI UX patterns from leading companies
- **Responsive Design**: Beautiful dark-themed interface with Tailwind CSS
- **Client-Side Routing**: Fast navigation with React Router

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Navigate to the project directory:
```bash
cd "C:\Users\harri\Documents\Claude Code\ai-website"
```

2. Install dependencies:
```bash
npm install
```

### Development

Start the development server:
```bash
npm run dev
```

The website will open automatically at `http://localhost:3000`

### Build for Production

Create an optimized production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```
